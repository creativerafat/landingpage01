# Frame: home — Exported from DesignKoro Studio

This repository contains both **standalone runnable HTML + CSS** and a **complete runnable React + CSS (Vite + TypeScript)** application generated from DesignKoro Studio.

## Option 1: Open HTML + CSS Directly
Open `index.html` (or any file in `frames/`) directly in your browser — all CSS styles and layout positioning are embedded and linked via `styles.css`.

## Option 2: Run React + CSS App
```bash
npm install
npm run dev
```
